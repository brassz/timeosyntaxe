- Status C / N.C / N.A para cada item

- Upload de múltiplas fotos por item
- Pré-visualização de fotos
- Armazenamento local (localStorage + IndexedDB)
- Geração de PDF profissional
- Histórico de checklists finalizados

- Interface mobile-friendly

## Formato das Versões

O projeto segue [Versionamento Semântico](https://semver.org/):
- **MAJOR** (X.0.0): Mudanças incompatíveis
- **MINOR** (0.X.0): Novas funcionalidades (compatível)
- **PATCH** (0.0.X): Correções de bugs (compatível)

---

## Tipos de Mudanças

- ✨ **Adicionado**: Novas funcionalidades
- 🔧 **Alterado**: Mudanças em funcionalidades existentes
- ⚠️ **Deprecado**: Funcionalidades que serão removidas
- 🗑️ **Removido**: Funcionalidades removidas
- 🐛 **Corrigido**: Correções de bugs
- 🔒 **Segurança**: Correções de vulnerabilidades
- 🎨 **Melhorado**: Melhorias visuais/UX
- 📚 **Documentação**: Apenas mudanças em docs
- ⚡ **Performance**: Melhorias de performance
